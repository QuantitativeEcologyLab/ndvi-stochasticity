This folder contains the following files (and their ancillary files):

- `ecoregions-polygons-edited.shp`: an edited version of `ecoregions-polygons.shp`, but with Africa and the Arabian Peninsula unified (independently)
- `ecoregions-polygons.shp`: an edited version of `../wwf-ecoregions/wwf_terr_ecos.shp` (see `../../analysis/003-ecoregion-polygons.R`)
- `ecoregions-qgis-project.qgz`: the QGIS project used to create `ecoregions-polygons-edited.shp` and `group-polygons.shp`
- `groups-polygons.shp`: an edited version of `../ecoregions-polygons.shp`, but with Africa and the Arabian Peninsula unified (independently)
